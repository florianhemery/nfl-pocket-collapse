# 🔴 MISTRAL AI - GUIDE RAPIDE

## ✅ Support Mistral activé !

### Comment connecter Mistral

1. **Clique sur "⚙️" (AI Settings)** en haut à droite
2. **Sélectionne "🔴 Mistral (Large, Small)"**
3. **Entre ta clé API Mistral**
4. **(Optionnel)** Spécifie le modèle :
   - `mistral-large-latest` (par défaut)
   - `mistral-small-latest`
   - `mistral-medium-latest`
   - `open-mistral-7b`
   - `open-mixtral-8x7b`
5. **Clique "Connect AI"**

---

## 🔑 Obtenir une clé API Mistral

1. Va sur [console.mistral.ai](https://console.mistral.ai)
2. Crée un compte / connecte-toi
3. Va dans **API Keys**
4. Clique **Create new key**
5. Copie la clé

## 🚀 Exemple d'utilisation

### 1. Configure Mistral
```
Provider: Mistral
API Key: [ta clé]
Model: mistral-large-latest
```

### 2. Pose des questions
```
👤 analyze SEA
🤖 [Analyse complète des Seahawks...]

👤 best teams
🤖 [Top 5 des défenses...]

👤 coverage analysis
🤖 [Insights sur tous les types de coverage...]
```

### 3. Mode Built-In (sans API)
Même sans clé API, l'IA fonctionne avec un moteur d'analyse intégré qui répond à toutes les questions de base sur les données.

## 🔧 Troubleshooting

### "❌ AI Error: ..."
- Vérifie que ta clé API est correcte
- Vérifie que tu as des crédits sur ton compte Mistral
- Essaie un modèle différent

### Le chat ne répond pas
- Rafraîchis la page (Cmd+R / Ctrl+R)
- Vérifie la console développeur (F12)
- Redémarre le serveur

### "⚠️ Please configure an AI provider first"
- Clique sur ⚙️
- Configure un provider
- Clique "Connect AI"
